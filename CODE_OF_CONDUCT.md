# Code of Conduct

In the Dark is a small, friendly project. The rule is simple: be decent.

- Be respectful and constructive. Assume good faith.
- No harassment, personal attacks, or discrimination of any kind.
- Keep criticism about the work, not the person.

## Reporting

If someone's behaviour is a problem, report it to the maintainer privately
through their GitHub profile. Reports are handled in good faith and in confidence.
